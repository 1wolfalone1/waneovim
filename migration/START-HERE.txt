--------------------------------------------------------------------
 0. BEFORE YOU START  (do this while you still have Windows+internet)
--------------------------------------------------------------------
If the Windows SSD uses BitLocker, suspend it FIRST. Step 1 below
changes BIOS settings, and that makes Windows demand a 48-digit
recovery key on its next boot. In Windows, as administrator:

       manage-bde -protectors -disable C:

Or save the key from  account.microsoft.com/devices/recoverykey
This cannot be fixed afterwards from Linux. Skip only if you are sure
BitLocker is off.

--------------------------------------------------------------------
 1. HARDWARE + BIOS
--------------------------------------------------------------------
Power off the old PC. Take out the SSD with serial 2404EE402177.
Put it in the new PC, in the M.2 slot NEAREST THE CPU (usually M.2_1).

Monitor cable goes into the GRAPHICS CARD, not the motherboard.
The 7800X3D has built-in graphics, so the motherboard port will show
you a perfectly normal BIOS - and then a black screen later.

First power-on of a new AM5 board takes 1-3 MINUTES OF BLACK SCREEN
while it trains the memory. This is normal. Do not power off. Do not
panic. Wait.

Press DEL to enter the BIOS and set:

       Secure Boot ................. Disabled
       CSM / Legacy Support ........ Disabled
       Integrated Graphics ......... Disabled   (or Auto)

Secure Boot is the big one - leave it on and the USB may refuse to
boot, or worse, everything works until the very last reboot and then
the machine only starts Windows.

Save and exit.

--------------------------------------------------------------------
 2. BOOT THE USB
--------------------------------------------------------------------
Plug in this USB stick. Power on, press the boot menu key
(F8 / F11 / F12 - the screen tells you) and pick the USB.

   If two entries show for the stick, pick the one starting "UEFI:".

Ventoy menu -> archlinux-x86_64.iso -> Boot in normal mode
   -> "Arch Linux install medium (x86_64, UEFI)"

Wait for the prompt:   root@archiso ~ #
There is no installer screen. A plain text prompt is correct.

--------------------------------------------------------------------
 3. RUN IT
--------------------------------------------------------------------
Type these three lines:

       mkdir -p /usb
       mount -L Ventoy /usb
       bash /usb/MIGRATION/RUN-ME.sh

It checks everything first and tells you if something is wrong. It
only touches the Arch disk. The Windows disk is never even opened.

Answer its questions. When it finishes:

       poweroff

Then PULL OUT THE USB and power on.

--------------------------------------------------------------------
 4. FIRST BOOT
--------------------------------------------------------------------
If it goes straight into Windows, that is NOT a failure.
Press the boot menu key and pick whichever entry is NOT
"Windows Boot Manager". Depending on the board it is called:

       Arch      or      UEFI OS      or      WD Blue SN580

Then set that entry first in the BIOS boot order.

--------------------------------------------------------------------
 5. AFTER YOU REACH THE DESKTOP
--------------------------------------------------------------------
Check the AMD card is driving it:

       lspci -k | grep -A3 VGA        # want: driver in use: amdgpu

Then finish up (this removes the NVIDIA driver - not needed to boot,
which is why it is a separate step):

       sudo bash ~/home-migration/06-post-boot-cleanup.sh

====================================================================
 WHEN THINGS GO WRONG
====================================================================

"mount: unknown filesystem type 'exfat'"
       modprobe exfat        then repeat step 3

"mount: /usb: can't find LABEL=Ventoy"
       blkid                 find the exfat line, note its device
       mount /dev/sda1 /usb  use that device name
       bash /usb/MIGRATION/RUN-ME.sh

USB will not mount at all - the scripts are on the Arch disk too:
       mount /dev/disk/by-uuid/4776357f-67c6-4d1e-86aa-9ca39a1c6f85 /mnt
       cp /mnt/home/thiencn/home-migration/05-uefi-convert.sh /root/
       umount /mnt
       bash /root/05-uefi-convert.sh

Script says the disk is not found
       Power off. Reseat the SSD in the M.2 slot nearest the CPU and
       check the little screw holds it flat. Check the BIOS storage
       page can see it.

Script stopped after saying the disk is now GPT
       Just run step 3 again. It is safe to rerun and will carry on
       from where it stopped. Do NOT reinstall. Do NOT format.

Anything else
       NOTHING IS EVER DELETED. Boot this stick again and you are
       back at a root prompt with the disk intact.
       Full notes:  less /usb/MIGRATION/GUIDE.md

No Windows entry in the GRUB menu - that is expected. Use the
firmware boot menu (F11) for Windows, or turn it on later with
GRUB_DISABLE_OS_PROBER=false in /etc/default/grub.
