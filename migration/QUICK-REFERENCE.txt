========================================================
 MOVING THIS DISK TO THE NEW AMD PC
========================================================

Your disk  : WD Blue SN580, serial 2404EE402177
Root UUID  : 4776357f-67c6-4d1e-86aa-9ca39a1c6f85
Boot UUID  : BA53-EA76

Device names (nvme0n1 etc.) CHANGE between machines.
Always match on the UUIDs above, never on the name.

--------------------------------------------------------
 STEP 1 - DO THIS NOW, ON THE OLD PC
--------------------------------------------------------

    sudo bash ~/home-migration/04-prep-for-new-pc.sh

Then REBOOT and confirm the old PC still starts normally.
This is safe. Nothing breaks. Do not skip the reboot check.

--------------------------------------------------------
 STEP 2 - WHEN THE NEW PC IS BUILT
--------------------------------------------------------

 a) Shut down the old PC. Remove the SSD with serial
    2404EE402177. Install it in the new PC.

 b) Plug in the Ventoy USB stick.

 c) Power on, press the boot menu key (F8 / F11 / F12).

 d) Choose the USB stick.  IMPORTANT: if the list shows two
    entries for it, pick the one starting with "UEFI:".

 e) Ventoy menu  -> archlinux-x86_64.iso
    then         -> "Boot in normal mode"
    then         -> "Arch Linux install medium (x86_64, UEFI)"

 f) Wait for the prompt:   root@archiso ~ #

 g) Type these five lines:

    mount /dev/disk/by-uuid/4776357f-67c6-4d1e-86aa-9ca39a1c6f85 /mnt
    cp /mnt/home/thiencn/home-migration/05-uefi-convert.sh /root/
    umount /mnt
    bash /root/05-uefi-convert.sh

 h) Read what it prints. It asks before changing anything.
    Answer y to continue.

 i) When it finishes: shut down, REMOVE THE USB, power on.

--------------------------------------------------------
 IF IT BOOTS INTO WINDOWS INSTEAD
--------------------------------------------------------

Not a failure. Press the boot menu key and pick "Arch".
Then set it first in the BIOS boot order.

--------------------------------------------------------
 AFTER YOU REACH THE DESKTOP
--------------------------------------------------------

    lspci -k | grep -A3 VGA     -> want "Kernel driver in use: amdgpu"

Old NVIDIA settings are kept at:
    ~/.config/hypr/nvidia.conf.nvidia-backup

--------------------------------------------------------
 IF SOMETHING GOES WRONG
--------------------------------------------------------

Boot the Ventoy stick again and you are back at a root
prompt with full access to the disk. Nothing is erased at
any point - your files are never touched.
